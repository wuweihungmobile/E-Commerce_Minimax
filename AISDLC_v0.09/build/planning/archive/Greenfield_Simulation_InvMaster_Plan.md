# Greenfield 情境模擬計畫：InvMaster 經銷存管理系統

**建立日期**: 2026-03-23
**模擬目的**: 以 QA 專家角色，完整模擬 AISDLC v0.09 Greenfield SOP 全流程，驗證 SOP 的完整性、合理性和可執行性
**目標專案**: InvMaster 專業經銷存管理系統
**技術棧**: React (Next.js) + Spring Boot + PostgreSQL + Android + macOS

---

## 模擬專案概述

**專案名稱**: InvMaster - 專業經銷存管理系統
**專案類型**: Type A Hybrid 架構（Web + Mobile + Desktop，共享後端 API）
**核心功能**:
- 進貨管理（採購訂單、供應商管理、進貨驗收）
- 銷貨管理（銷售訂單、客戶管理、出貨追蹤）
- 庫存管理（庫存查詢、盤點、調撥、安全庫存警示）
- 手機掃碼操作（Android 掃碼入庫/出庫、macOS 管理端操作）

**模擬情境**:
1. **新增情境**: 新增商品、新增進貨單、新增銷貨單
2. **修改異動情境**: 修改商品資訊、修改訂單、庫存調整
3. **刪除情境**: 刪除商品、作廢訂單、庫存盤虧處理

## 模擬原則

1. **逐步執行**: 每個步驟都仔細執行，不跳過
2. **情境驗證**: 新增/修改/刪除三種情境都完整走過
3. **問題記錄**: 發現問題立即記錄，不等模擬結束
4. **多平台驗證**: Web + Android + macOS 三平台都要考慮
5. **追蹤鏈驗證**: Feature → BR → Epic → US → AC → API → TC 完整鏈
