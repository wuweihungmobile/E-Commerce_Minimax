## 4. Sprint 15 User Stories

### US-001: 商家回覆評價功能

**描述**:
作為 StoreOwner，我希望能回覆買家的評價，以便與顧客建立良好的溝通。

**驗收標準**:
- [ ] AC-001: StoreOwner/StoreStaff 可對評價提交回覆
- [ ] AC-002: 回覆顯示在評價下方（買家可見）
- [ ] AC-003: 每筆評價僅能回覆一次，不可修改

**技術備註**:
- 新增 `review_replies` 表
- 通知買家收到回覆（M09 整合）

**依賴**:
- M08 評價系統 Phase 1 已完成

---

### US-002: 結算單生成基礎

**描述**:
作為系統，我需要建立結算單生成機制，以便商家可以查看每週收益結算狀態。

**驗收標準**:
- [ ] AC-001: 每週一自動生成上週結算單
- [ ] AC-002: 結算單包含訂單總數、GMV、退款金額、平台抽成、結算金額
- [ ] AC-003: 商家可透過 API 查詢結算單狀態

**技術備註**:
- settlement_statements 表使用 (§8.2.9)
- Scheduled Job 每週執行
- Admin 審核流程 (§7.2.1 規格)

**依賴**:
- M05 訂單履約系統已完成
- M07 金流 Phase 2-A 已完成

---

### US-003: 結算單審核流程

**描述**:
作為 Admin，我需要審核商家結算單，以便確保結算金額正確。

**驗收標準**:
- [ ] AC-001: Admin 可查看所有待審核結算單
- [ ] AC-002: Admin 可批准或駁回結算單
- [ ] AC-003: 駁回時需填寫原因

**技術備註**:
- Admin 角色權限驗證
- 審核日誌記錄

**依賴**:
- US-002 結算單生成已完成

---

### US-004: 評價標記功能

**描述**:
作為 StoreOwner，我希望能標記評價的處理狀態，以便管理客服工作流程。

**驗收標準**:
- [ ] AC-001: 可標記評價為「已處理」
- [ ] AC-002: 可篩選「已處理/未處理」的評價列表
- [ ] AC-003: 標記狀態變更時記錄時間戳

**技術備註**:
- 新增 `is_handled`, `handled_at` 欄位至 reviews 表

**依賴**:
- M08 評價系統 Phase 1 已完成
